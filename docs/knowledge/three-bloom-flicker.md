# three.js の bloom（UnrealBloomPass）がチカチカする

対象: `three/examples/jsm/postprocessing/UnrealBloomPass.js` を `EffectComposer` で使う場合。対策のコードは `src/scripts/core/three/StableBloom.ts`。

## 症状

- 細い光の線・小さな光の点など、明るくて細いものの周りの bloom が、動くたびに細かくチカチカする。
- 止まっていると目立たず、ゆっくり動くと特に目立つ。
- `bloom` を切ると消える。強さ（strength）を 0 にしても消える。bloom の中で起きている、と切り分けられる。

## 原因（重なりやすい順）

1. **明るいところの抜き出しが 1 点読み**: UnrealBloomPass は、元の画像から明るいところを抜き出すとき、1 ピクセルにつき 1 回だけ読む。しかも、渡した解像度のさらに半分のバッファに書く。細い光が 1 ピクセル未満だけ動いても、拾われたり拾われなかったりする。
2. **段ごとに解像度を落とす**: そのあと、半分ずつ小さくしながら何段もぼかす。最初のゆれが段ごとに広がる。渡す解像度を下げるほど、ひどくなる（画面の 1/4 から始めると、かなり目立つ）。
3. **しきい値の幅がほぼ 0**: 既定の `smoothWidth` は 0.01 で、ほぼ硬い切り替え。しきい値付近の明るさの光は、bloom が付いたり消えたりする。
4. **しきい値を大きく超える明るい点**: しきい値の何倍も明るい細いものは、わずかな位置や明るさの変化でも bloom の量が大きく増減する。
5. **細すぎる光そのもの**: 1 ピクセル前後の点や線は、bloom がなくても動くたびに明るさがゆれる。bloom はそれを広げる。

## 対策

| # | 対策 | 効き方 |
|---|---|---|
| 1 | 抜き出しを、周りの点の平均にする（4×4 の範囲を 4 回の補間読み＋中心で平均。明るい点ほど重みを下げる＝Karis average） | 1 点読みのゆれが消える。`StableBloom` が差し替える |
| 2 | 合成した bloom を、前のフレームと混ぜる（時間方向にならす） | 残ったゆれをならす。bloom は柔らかく広いので、動きの遅れはほぼ見えない。混ぜすぎると、動く小さな明るいもの（プレイヤーが操作するものなど）が尾を引いてぼやける。0.5〜0.7 が目安 |
| 3 | パスに渡す解像度は、描画バッファと同じにする（抜き出しは画面の半分から） | 半分を渡すと画面の 1/4 から始まり、ゆれが倍以上になる |
| 4 | しきい値に幅を持たせる（`smoothWidth` 0.3 前後） | 付いたり消えたりがなめらかな増減になる |
| 5 | 明るすぎるものを抑える（しきい値の 2〜3 倍程度まで） | bloom の量の増減が小さくなる。光って見せたいものは、加算の柔らかい光（ハロー）を重ねて補う |
| 6 | 点・線に最小の太さを持たせる（例: 点 2px、線 1.5px）。細い分は暗くして面積で釣り合わせる | 細すぎる光のゆれを元から減らす |

1〜4 を入れたあとなら、bloom の強さと範囲を大きめにしても、チカチカは戻りにくい。

## 測り方（効いたかを数字で確かめる）

見た目だけで判断すると迷うので、数字で比べる。

1. Playwright などで、実機の GPU で開く（ソフトウェア描画では結果が変わる）。
2. 動きをごく遅くする（タイムスケールを 0.1 など）。速いと、動きそのものの変化が混ざる。
3. 光っているものがある範囲を連続で撮り、範囲の平均の明るさを並べる。
4. 2 階差分の絶対値の平均 `mean(|v[i] - 2 v[i-1] + v[i-2]|)` を「ゆれ」とする。ゆっくりした変化は消え、細かいゆれだけが残る。
5. 条件を変えて比べる（bloom なし／強さ 0／対策あり・なし）。順番を入れ替えて繰り返す。場面が変わると値がばらつくため。
6. 範囲を速く横切る前景の物体は、消して測る。動きがゆれとして数えられてしまう。

ある例での値（細く明るい図形が横にゆっくり動く場面）: 対策前 0.35 → 解像度を合わせる 0.15 → 抜き出しの差し替え 0.08 → 前のフレームと混ぜる 0.65 で 0.04〜0.12、0.8 で 0.02 前後。bloom なしは 0.001。混ぜる割合は上げるほどゆれが減るが、動く小さな明るいものがぼやけるので、見た目との兼ね合いで決める（`StableBloom` の既定は 0.65）。場面によって値は大きくばらつくので、比べるのは同じ測り方の中だけにする。
